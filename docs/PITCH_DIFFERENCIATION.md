# Différenciation DigiScore-WA

Les autres groupes proposeront surtout : formulaire → score 0–100 → oui/non. Nous livrons un **copilote d’éligibilité et de plafond**.

## Cinq preuves

1. **Crédit télécom SFD** — éligible / non, montant plafonné, message explicite (« demande > plafond : X proposés »).
2. **Membre préalable** — pas de dossier orphelin ; l’historique institutionnel (ou preuves externes) est la source de vérité.
3. **Trois niveaux humains** — Agent → Chef d’agence → CIC, audit, override motivé. Jamais d’octroi robot.
4. **Méthode CIF / FUCEC digitalisée** — CAF, RCSD, 6 critères /100, N1–N3, cautions, BIC/fiscal. Pas une boîte noire importée.
5. **Sidecar déployable** — mapping de champs, adapters, tables ADD-only. On ne remplace pas le SI.

## Phrase 20 secondes

On n’attend pas le pilote pour être intégrable : DigiScore est un sidecar avec mapping, tables en ajout seul, et un adapter qu’on branche sur vos APIs sans toucher au transactionnel ni au moteur de score.

## Ce qu’on ne vend pas

« On a mis de l’IA » sans données réelles. Un score /100 seul. Remplacer le comité.
